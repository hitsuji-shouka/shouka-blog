# REQ-20260613-06-trace PRD

> 文档版本：v1.0 | 创建日期：2026-06-13 | 状态：定稿 | 依赖：REQ-20260613-02, 03, 04

## 1. 背景与目标
LLM 入口已多（助理 RAG 问答、理财/AI 每日汇总）。上 Langfuse 自托管做调用追踪：记录 prompt、检索命中、回答、模型、token、耗时，可视化排查与后续 eval 基础。

## 2. 用户故事
| 角色 | 期望 | 目的 |
|------|------|------|
| shouka | 看每次助理问答全过程 | 排查检索/回答质量 |
| shouka | 看每日汇总调用 | 监控 token/耗时/失败 |

## 3. 功能需求
### 3.1 接入点
- backend chat：/api/chat 一次问答一条 trace，含 embedding 检索（命中 slug/相似度）+ DeepSeek 流式生成 span。
- pipeline summarize：每次汇总一条 trace，输入条数/模型/token。
- 失败也记（error span），不影响主流程；无 key 时静默禁用不报错。
### 3.2 自托管
- docker compose 加 langfuse + postgres；key 走 env；本地/服务器均可。
### 3.3 非目标
- 不做 eval（下一子需求）；不追前端；不改对话/报告功能。

## 4. 数据模型
trace：name、input(messages)、output、metadata(model/token/latency/sources)；嵌套 span：retrieve、generate。Langfuse 内置存储。

## 5. 非功能
追踪异步/失败不阻断；key 仅后端 env；无 key 降级关闭。

## 6. 验收标准
- [ ] Given 配 LANGFUSE key，问助理，Then Langfuse 出一条 trace 含检索命中+回答+token
- [ ] Given pipeline 跑，Then 出汇总 trace
- [ ] Given 无 key，Then 功能照常、不报错、不追踪
- [ ] Given LLM 异常，Then trace 记 error，主流程不崩
