# REQ-20260613-05-essays PRD

> 文档版本：v1.0 | 创建日期：2026-06-13 | 状态：定稿 | 依赖：REQ-20260612-01

## 1. 背景与目标
阅读/音乐/影评零散，合并为「随笔」。四分类 AI/阅读/音乐/理财 → 三分类「科技/理财/随笔」（AI→科技，阅读+音乐+影评→随笔）。随笔支持 markdown 图文/链接，图片走 GitHub 图床外链，前端渲染优化。

## 2. 用户故事
| 角色 | 期望 | 目的 |
|------|------|------|
| shouka | 随笔里插图片/链接，渲染好看 | 图文记录 |
| shouka | 图丢 content/images push 即引用 | 不碰对象存储 |
| 访客 | 三栏清爽 | 易逛 |

## 3. 功能需求
### 3.1 分类
科技(原 AI)、理财、随笔(原阅读+音乐)。后端枚举三分类；现有文章 frontmatter 改 科技/随笔；前端 CATS/徽章色/导航。
### 3.2 随笔渲染
markdown 图片 `![](url)` 自适应宽度圆角；链接配色；保留五平台嵌入；图床用 GitHub raw（content/images/）。
### 3.3 兼容
理财/科技仍分原创/报告；随笔单列。

## 4. 数据模型
Category 枚举改 [科技,理财,随笔]；frontmatter 沿用；content/images/ 存图。

## 5. 非功能
图床外链失效图裂；纯前端无新接口无上传无鉴权。

## 6. 验收标准
- [ ] Given 重命名，导航显示 科技/理财/随笔，无阅读/音乐
- [ ] Given 随笔含图片 markdown，详情页自适应渲染
- [ ] Given 随笔含链接，可点；嵌入指令仍渲染
- [ ] Given 科技/理财报告 tag，RAG 仍跳过
