# REQ-20260613-04-ai-daily 系统设计

> v1.0 | 2026-06-13 | 对应 PRD：REQ-20260613-04 | 依赖：REQ-20260612-01, 03

## 1. 架构概览
两步：①分类「学习」→「AI」全量重命名；②AI pipeline 复用 REQ-03，参数化 category+源名单，理财/AI 共用 fetch/summarize/report/run。报告 tag「每日报告」沿用，RAG 跳过，AI 页分原创/报告（与理财页同逻辑）。

## 2. 重命名影响
- backend/models.py Category 学习→AI；content/2026-06-12-hello-shoka.md category 改 AI。
- frontend/lib/cat.ts CATS 学习→AI、CAT_COLOR 加 AI=blue；Category.tsx 分区判断扩到 AI（理财+AI 均分区）。
- 兼容：枚举值变更，旧学习文章须改 frontmatter，无旧数据外泄。

## 3. pipeline 参数化
- bloggers.toml → 多组：finance.handles、ai.handles + ai.wechat（公众号名）。
- run.py 接 category 参数：选源 → fetch → summarize(领域 system) → report.write(category, slug 前缀)。
- report.write(summary, category, prefix)：理财 finance-、AI ai-；tag 每日报告共用。
- 公众号 fetch：CDP 搜公众号近文，反爬降级跳过记日志。

## 4. 前端分区
Category.tsx：name∈{理财,AI} 时按 tag 分原创/报告，余单列。

## 5. 部署/安全
pipeline 本地，CDP 登录态；新 ai cron。仅聚合公开内容附原链。报告 md push 上线，服务器零改。
