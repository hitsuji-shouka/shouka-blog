# REQ-20260613-06-trace 系统设计

> v1.0 | 2026-06-13 | 对应 PRD：REQ-20260613-06

## 1. 概览
Langfuse 自托管，backend chat 与 pipeline summarize 包 trace。langfuse SDK @observe/低层 API，无 key 自动降级（no-op）。compose 加 langfuse+postgres。

## 2. 接入
- backend/trace.py：init langfuse(从 env)，提供 observe 包装；无 key 返 no-op。
- chat.py stream：trace「chat」→ span retrieve(命中 sources/sim) + span generate(model/token/输出)。
- pipeline/summarize.py：trace「daily-summary」(category, 条数, model, token)。
- 异常 try 包，记 error 不抛。
- config 加 LANGFUSE_PUBLIC/SECRET/HOST。

## 3. 部署
docker-compose 加 langfuse-server + postgres；env 注 key。本地开发可指云或自托管实例。

## 4. 兼容
不动 /api/chat 契约与报告产物；trace 旁路。
